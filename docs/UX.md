# UX / UI 설계 기준

문자 관리 시스템의 화면 설계 기준이다. 화면을 바꾸기 전에 읽고, 바꾼 뒤에는 이 문서의 체크리스트를 확인한다.
(시각 토큰의 원본은 `DESIGN.md`(Apple 스타일 참고 자료)와 `src/views.js`의 CSS 변수다.)

## 1. 사용자와 핵심 과업

| 사용자 | 하는 일 | 빈도 |
|---|---|---|
| 직원(일반 사용자, 부서별) | 면접 대상자에게 안내 문자 보내기 → 사업장별 참석/불참 확인 | 주 단위, 몰아서 |
| 일반 관리자 | 한두 명에게 문자 보내기/예약, 받은 문자에 답장 | 수시 |
| 관리자 | 폰 연결, 부서·계정 관리, 인증 대기자 승인 | 드물게 |

핵심 원칙: **초보자도 설명 없이 끝까지 간다.** 한 화면에 주요 동작 하나, 숫자 먼저, 설명은 짧게, 되돌리기 어려운 동작은 한 번 더 묻는다.

## 2. 정보 구조(IA)

```
문자 관리
├ 홈        오늘 요약(보낸/받은/예약/확인 필요) · 최근 받은 문자 · 진행 중인 면접 안내
├ 문자 보내기  받는 번호(여러 명) · 내용(바이트 표시) · 지금/예약
├ 문자함      전체 | 받은 문자 | 보낸 문자 | 예약 문자   (답장, 예약 취소)
├ 면접 안내    목록 → 만들기(명단·사업장·문구·시간) → 상세(사업장별 회신 현황, 사람별 현황)
└ 설정(전체 관리자)  문자 보내는 폰 · 폰 연결 안내(1~7) · 사용자와 부서
사용자 메뉴: 비밀번호 바꾸기 · 기록 보기 · 로그아웃
로그인 전: 로그인(이메일+비밀번호) · 회원가입 · 이메일 인증 안내 · 비밀번호 재설정
```

- 상단 메뉴(데스크톱)와 하단 탭 바(모바일, 5개)는 같은 항목이다. 현재 위치는 `aria-current="page"`.
- "예약 문자"는 별도 메뉴 대신 문자함 탭으로 둔다(같은 목록의 다른 보기).
- 면접 안내는 "문자 관리" 안의 하나의 기능이다. 홈과 메뉴에서 같은 위계로 노출한다.

## 3. 용어(한 가지 말만 쓴다)

| 쓴다 | 쓰지 않는다 |
|---|---|
| 문자 보내는 폰 | 게이트웨이, 디바이스 |
| 면접 안내 | 캠페인 |
| 답장 받기 | 웹훅 |
| 사업장(원가중심점) | 지점, 사이트 |
| 확인 필요 | unclear, 판독 불가 |
| 답 없음 | 미응답, sent |

## 4. 화면 패턴

- **페이지 머리말**: 제목 + 한 줄 설명 + 오른쪽 주요 동작 (`pageHeader`). 상세 화면은 위에 "← 목록" 링크.
- **숫자 카드**(`stat`): 큰 숫자 + 라벨. 의미가 있을 때만 색(참석 초록, 불참 빨강, 확인 필요 보라, 답 없음 호박).
- **상태 뱃지**(`badge`): 항상 글자 + 색. 색만으로 구분하지 않는다.
- **응답 막대**(`responseBar`): 면접 안내의 응답 구성을 한눈에. 색 + 숫자 범례 병기.
- **목록**: 문자함은 카드 목록(번호·뱃지·시각 / 본문 / 동작). 표는 숫자 비교가 필요할 때만(사업장별 현황, 지원자).
- **빈 상태**(`emptyState`): 무엇이 비었는지 + 다음 행동.
- **알림**(`.notice`): ok/info/warn + 아이콘. 오류는 `role="alert"`.
- **확인 창**: 여러 명에게 보내기, 다시 보내기, 멈추기, 예약 취소는 `data-confirm`.
- **표시 형식**: 전화번호 `010-1234-5678`(`fmtPhone`), 시각 `오늘 13:58`·`10/20(화) 14:00`(`fmtWhen`). 원본 값을 그대로 노출하지 않는다.

## 5. 주요 흐름

**면접 안내**: 만들기(명단 → 사업장 → 문구·미리보기 → 보내는 시간) → 올리기(아직 발송 안 됨을 명확히) → 상세에서 "지금 바로 보내기" 또는 예약 → 사업장별 회신 현황 → 확인 필요 항목 직접 확정 → 답 없는 사람 다시 보내기 → 엑셀 저장.

**문자 보내기**: 번호(인원수 실시간) → 내용(바이트, 단문/장문 표시) → 지금/예약 → 결과 알림 + 문자함 링크.

**폰 연결(설정)**: 상태 → "폰 연결하기" 1~7 단계 → 연결 확인 → 받기 시험.

## 6. 반응형

- 기준 폭: 데스크톱 최대 1080px, 폼 열 720px. 720px 이하는 하단 탭 바 + 1열 + 표를 카드로 변환(`table.cards`).
- 터치 대상 44px 이상, 입력 48px. 본문 16px 이상.

- [x] 모든 입력에 보이는 `label`(placeholder 만으로 설명하지 않음)
- [x] 포커스 링 3px, 키보드만으로 모든 동작 가능

## 9. 2026-10-15 UX 검토에서 고친 것

| 문제 | 조치 |
|---|---|
| 표가 카드 안에서 내용 폭만큼만 차지, 오른쪽이 비어 보임 | 표 틀(`.table-wrap`) + 100% 폭, 모바일은 카드 변환 |
| 메뉴 7개 + 사용자 링크가 한 줄, 현재 위치 표시 없음, 모바일에서 줄바꿈 | 5개 메뉴 + 현재 위치 강조, 사용자 메뉴로 정리, 모바일 하단 탭 |
| 홈의 큰 제목/타일이 메뉴와 중복, 핵심 숫자가 아래에 묻힘 | 홈을 "요약 → 최근 받은 문자 → 진행 중 면접 안내"로 재구성 |
| 이모지 아이콘이 제각각, 상태가 글자 색으로만 구분 | 선 아이콘 세트, 상태 뱃지/응답 막대 |
| 전화번호·시각 원본 노출(01012345678, 2026-10-15 13:58) | `fmtPhone`/`fmtWhen` |
| 로그인에 라벨/브랜드 없음, placeholder 만 사용 | 라벨 + 로고 + 설명, 가운데 정렬 |
| 문자 작성 시 인원수·길이 피드백 없음 | 실시간 인원수, 바이트·단문/장문 표시 |
| 대량 발송/취소에 확인 없음 | 확인 창(`data-confirm`) |
| 설정 화면이 표+버튼 나열 | 폰 카드(상태·주 동작·더 보기)와 단계 안내를 분리 |
| 면접 안내 만들기의 폼 폭/정렬 불일치 | 720px 단일 열, 단계 카드, 표본 표 |

## 개선 이력: 빠른 개선 (A1~A7, 2026-10)
- 지원자 관리(모바일): 선택 체크칸을 카드 오른쪽 위로 고정, "지원자 추가"는 접힌 상자(데스크톱은 열림)로, 문자 시스템 연결 설정은 목록 아래로 → 목록이 첫 화면에 보이도록.
- 문자함: "답장"을 별도 줄이 아니라 항목 오른쪽 아래 아이콘으로 → 항목 높이 감소.
- 면접 안내 상세: 자동 리마인드를 켜짐/꺼짐 **스위치**(`.tgl`)로.
- 로그인·가입(모바일): 위쪽 정렬, 위에 "문자 관리 시스템" 표기.
- 작은 버튼(`.small`)은 모바일에서 높이 44px 이상.
- 결과 안내용 주소 조각(`ok`, `err`, `n`, `k`)은 화면이 뜬 뒤 주소에서 제거 → 새로 고침 시 안내가 다시 나오지 않음.
- 남은 개선(검토 문서): 사람 화면 통합(지원자 이력 ↔ 지원자 관리), 모바일 하단 탭 재구성, 홈 "오늘 할 일" 상단 배치, 설정 구역 탭, 확인 창 교체.

## 개선 이력: 구조 개선 (B1~B5, 2026-10)
- **B1 사람 화면 통합**: "지원자 이력"은 **면접 안내 이력**으로 이름을 바꾸고 지원자 관리 안으로 옮김. 지원자 관리 맨 위에 `지원자 목록 | 면접 안내 이력` 탭. 면접 안내 이력의 각 사람에 지원자 관리 등록 여부(등록됨 / 블랙리스트 / "지원자로 등록" 버튼)를 표시. 면접 안내 목록의 "지원자 이력" 버튼은 제거. (`/people` 주소는 그대로 유지)
- **B2 모바일 하단 탭**: 홈 · 보내기 · 문자함 · 면접 · **더보기**. 더보기 시트에 지원자 관리, 설정(관리자), 내 계정, 폰 설치 안내, 기록 보기(관리자), 로그아웃.
- **B3 홈**: **오늘 할 일**(확인이 필요한 답장 / 안 읽은 받은 문자 / 최근 7일 미회신 / 예약 대기)을 맨 위로. 이어서 면접 안내 현황 → 면접 안내 → 최근 받은 문자 → 오늘의 숫자 → 이번 달 대신한 일. 할 일이 없으면 "지금 처리할 일이 없어요".
- **B4 설정**: 구역 이동 칩(문자 보내는 폰 / 시스템 상태 / 폰 연결하기 / 사용자 / 부서), 위쪽에 고정.
- **B5 지원자 줄 행동**: 수정 · 기록 + **더 보기**(블랙리스트 등록 / 해제 / 사유 수정 / 상세 화면). 메뉴는 줄 안에서 펼쳐져요.
- 남은 개선: 확인 창을 화면 안 대화상자로 교체, 제출 중 표시, 접근성 점검(키보드·스크린 리더), 실제 사용자 관찰.

## 개선 이력: 상호작용·접근성 (C, 2026-10)
- **확인 대화상자**: 브라우저 기본 `confirm` 대신 화면 안 대화상자(`<dialog>`). 위험한 문구(삭제·해제·되돌리기)는 빨간 확인 버튼, 기본 포커스는 "취소". `Esc`나 바깥을 누르면 취소. 구형 브라우저는 기본 창으로 대신함. 양식에 `data-confirm="문구"`만 달면 됨(`src/appjs.js`).
- **제출 중 표시**: 제출하면 해당 양식의 버튼을 잠그고(`aria-busy`) 누른 버튼에 "처리 중…"을 표시, 두 번 눌러도 한 번만 전송. 뒤로 가기로 돌아오면 새로 읽음.
- **안내 정리**: 저장 완료 안내(초록)는 8초 뒤 사라지고 눌러서 닫을 수 있음(되돌리기 같은 누를 것이 들어 있는 안내는 그대로). 결과용 주소 조각은 주소에서 제거.
- **접근성**: 표 머리글 `scope="col"`, 더보기 시트 `Esc`로 닫기·포커스 복귀, 확인 창은 모달(포커스 가둠). 이전부터 있던 것: 건너뛰기 링크, `:focus-visible` 표시, 움직임 줄이기 설정 대응.
- **색 정리**: 응답 막대·범례의 "답 없음"을 무거운 갈색에서 연한 호박색(`--amber-bar`)으로, 뱃지(연한 배경 + 진한 글자)와 톤을 맞춤.
- 아직 안 한 것: 스크린 리더 실제 점검, 색 대비 자동 측정, 실제 사용자 관찰.

## 10. 채용 워크플로우 개편 (2026-10-17, `docs/WORKFLOW.md`)
- 메뉴(일의 순서): **홈 · 지원자 · 면접 · 문자함 · 설정**. 모바일 하단 탭: 홈 · 지원자 · 면접 · 문자함 · 더보기(문자 보내기·설정·내 계정·폰 안내·기록). 문자 보내기는 문자함의 "새 문자".
- 홈 = 오늘 할 일(오늘 면접 → 확인 필요 → 등록할 새 지원 → 연락처 대기 → …) + 면접 안내 현황 + 이번 달 대신한 일. 주 버튼 "면접 안내 만들기".
- 면접 안내 상세: 숫자(누르면 그 상태로 걸러짐) → 처리할 답장 안내 → 사람별 표 → 사업장 표 → 결과·자동 문자·보낸 문자. 행 동작은 상태별(확인 필요만 참석/불참을 앞에, 나머지는 "바꾸기"에 접음).
- 오늘 면접(`/interviews/today`): 시간순, 행마다 48px [출석][노쇼], 날짜 이동.
- 사람은 이름으로: 문자함은 번호 옆에 이름과 면접 안내를 보여 준다. 시스템 문자는 "자동", 1분 안에 나갈 문자는 "곧 보냄".

## 9. 지원자 관리 작업 공간 (2026-10 개편)

**과업 모델**: 알바몬 지원이 들어온다 → 연락처를 확인한다 → 원가중심점을 정한다 → 지원자로 등록한다 → (필요하면) 찾고·블랙리스트를 관리한다. 설정(자동 수집)은 처음 한 번뿐이라 매일 쓰는 화면에서 치운다.

```
지원자 관리
├ 새 지원     숫자 카드(대기·연락처 필요·분류 필요·등록 가능) → 걸러 보기 → 카드(연락처→분류→등록) · 일괄 처리 막대 · 처리됨 보기
├ 지원자      검색 한 줄(번호면 즉시 확인) · 칩 · 표(행 = 상세로) · 추가/올리기 대화 창 · 일괄 처리 막대
│  └ 상세     머리(이름·번호·상태·문자 보내기·수정) · 지원 이력 · 면접 이력 · 변경 기록 | 블랙리스트 상태 · 관리
├ 공고 정리   공고 카드 → 원가중심점·직무 한 번에 적용(정리 필요/정리 끝)
├ 면접 이력   같은 번호로 묶은 면접 안내 이력
└ 연결 설정   확장 설치 → 그룹웨어 계정 → 알바몬 로그인 / 고급(키·전달 주소·공용 주소·북마크)
```

**원칙**
1. 한 화면 = 한 가지 일. 입력 폼은 필요할 때만 펼치거나(분류하기) 대화 창으로 연다(추가·올리기·수정·블랙리스트).
2. 카드/행마다 **다음 할 일**이 눈에 보인다(연락처 없음 → "연락처 가져오기", 있음 → "등록"). 주 동작은 오른쪽 아래.
3. 숫자 카드는 곧 필터다(누르면 걸러짐). 선택하면 아래 **일괄 처리 막대**가 나타난다.
4. 상태는 글자+색 뱃지(연락처 있음/가져오는 중/실패, 분류 필요/원가중심점·직무, 블랙리스트).
5. 모바일은 표 대신 카드, 대화 창은 아래에서 올라오는 시트.
6. 설정·위험한 동작(삭제·합치기)은 일상 흐름에서 떨어뜨린다(연결 설정, 상세의 "관리").
