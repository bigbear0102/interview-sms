## 3. 확인한 것 (문제 없음)

- 권한: 면접 안내 동작(일정·다시 안내·결과 문자)·오늘 면접 기록은 부서 권한 확인. 다른 부서 면접은 오늘 면접·진행 단계에 보이지 않음(시험 있음).
- CSRF: 세션 쿠키 SameSite=Strict + POST Origin 검사. XSS: 새 화면 출력은 모두 `esc`.
- 시간: KST 고정, 면접일시 "10/22(수) 15:00" 형식 해석, 날짜 경계(오늘 면접 전날·다음 날).
- 자동 문자 중복 방지: 리마인드·한 번 더·결과 문자·확정 문자 모두 한 번만(선점 표시). 기존 안내에는 새 자동 문자 꺼짐.
- 운영: 최근 3일 오류 0건, D1 읽기 하루 6만~19만 행(한도 500만).
- 실제 폰 시험(관리자 번호): 발송·전달·되돌아온 문자 무시·번호 답장·확정·다시 안내·결과 문자.
