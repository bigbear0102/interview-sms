# 사용 안내 (처음 쓰는 분용)

면접 보는 분들에게 문자로 안내를 보내고, "참석" / "불참" 답장을 자동으로 모아서 보여 주는 시스템이에요.

- 접속 주소: **https://interview.bigbears.me**
- 화면의 안내 글은 이 문서와 같은 내용이에요. 막히면 화면의 안내를 그대로 따라 하면 돼요.

## 전체 흐름 (3단계)

1. **폰 연결** — 문자를 보낼 회사 폰을 시스템에 연결해요. (폰 1대당 한 번만)
2. **명단 올리고 보내기** — 엑셀 명단 파일을 올리고 "지금 바로 보내기"를 눌러요.
3. **결과 보기** — 참석 / 불참 / 답 없음 숫자를 사업장별로 확인해요.

---

## 1단계. 폰 연결하기 (전체 관리자만)

웹의 **설정** 화면에 1~6번 단계가 큰 글씨로 나와 있어요. 복사 버튼도 있어요. 아래는 같은 내용이에요.

### 1) 앱 설치하기
1. 폰에서 **인터넷(크롬)**을 열어요.
2. 주소 칸에 `github.com/capcom6/android-sms-gateway/releases` 를 입력하고 이동해요.
3. 맨 위 최신 버전에서 **Assets**를 눌러 펼쳐요.
4. 이름이 **.apk**로 끝나는 파일을 눌러요. (이름에 `insecure`가 들어간 것은 고르지 마세요.)
5. 다운로드가 끝나면 **열기** → **설치**를 눌러요. "이 출처 허용" 화면이 나오면 스위치를 켜고 뒤로 가서 다시 **설치**를 눌러요.
6. 설치가 끝나면 **열기**를 눌러 **SMSGate** 앱을 열어요.

### 2) 문자 보내기 허용하기
1. 앱을 열면 "문자를 보내도록 허용할까요?" 창이 나와요. **허용**을 눌러요.
2. "전화 걸기/관리" 창이 나오면 그것도 **허용**을 눌러요.

**허용 버튼이 회색이라 눌리지 않을 때** (갤럭시 폴드 등에서 자주 생겨요)
1. 안 눌리는 **허용** 버튼을 **한 번 눌러 보고** 나와요.
2. **설정** 앱 → **애플리케이션**(또는 **앱**) → **SMSGate**를 눌러요.
3. 화면 **오른쪽 위 점 세 개(⋮)**를 눌러요.
4. **제한된 설정 허용**을 누르고, 지문이나 비밀번호로 확인해요.
5. 뒤로 가서 **권한** → **문자(SMS)** → **허용**을 눌러요.

### 3) 폰이 꺼지지 않게 설정하기
1. **설정** 앱 → **애플리케이션** → **SMSGate** → **배터리**
2. **제한 없음**을 선택해요.
3. 이 폰은 **충전기에 계속 꽂아 두고** 전원을 켜 두세요.

### 4) 앱에 서버 정보 넣기
웹 **설정** 화면 4번에 **서버 주소**와 **비밀 번호표**가 있어요. 각각 **복사하기**를 누르고 폰에 붙여넣어요.
(컴퓨터에서 복사한 글자를 폰으로 옮기기 어려우면, 카카오톡 "나와의 채팅"에 붙여넣고 폰에서 열어 복사하면 편해요.)

1. 앱 아래쪽 메뉴에서 **Settings**(설정)를 눌러요.
2. 아래로 내려 **Cloud Server**를 눌러요.
3. **API URL** 칸에 서버 주소를 붙여넣어요. (칸을 길게 누르면 **붙여넣기**가 나와요.)
4. **Private Token** 칸에 비밀 번호표를 붙여넣어요.
5. 저장(✔) 버튼이 있으면 눌러요.

### 5) 켜기
1. 앱 아래쪽 메뉴에서 **Home**을 눌러요.
2. **Cloud server** 스위치를 **켜요**.
3. **Offline** 버튼을 눌러요.
4. 버튼이 **Online**으로 바뀔 때까지 기다려요. (몇 초)

Online이 안 되면: 서버 주소에 빠진 글자가 없는지, 폰이 인터넷에 연결되어 있는지 확인해요.

### 6) 아이디와 비밀번호 옮겨 적기
1. 앱의 **Settings → Cloud Server** 화면에 **Username**(아이디)과 **Password**(비밀번호)가 보여요.
2. 웹 **설정** 화면 6번 칸에 똑같이 적고, 부서를 고른 뒤 **연결 끝내기**를 눌러요.
3. **연결된 폰** 목록에서 **잘 연결됐는지 확인**을 눌러 "잘 연결되어 있어요"가 나오면 끝이에요.

> 앱을 지우고 다시 설치하면 아이디와 비밀번호가 새로 바뀌어요.
> 이때는 목록의 **폰을 다시 설치했어요**를 눌러 새 값을 적어 주세요.

## 2단계. 명단 올리고 보내기

웹 위쪽 **면접 안내 보내기**를 눌러요.

1. **명단 파일 고르기** — 엑셀에 `사업장, 이름, 전화번호, 면접일시`를 적고 **CSV로 저장**한 파일이에요. **연습용 양식 받기**를 누르면 예시 파일이 내려와요.
2. **보낼 문자 확인하기** — `{이름}`, `{사업장}`, `{면접일시}` 자리에는 사람마다 맞는 정보가 저절로 들어가요.
3. **명단 올리기**를 눌러요. → 이때는 **아직 문자가 나가지 않아요.**
4. 다음 화면에서 초록색 **지금 바로 보내기**를 누르면 문자가 나가요. 나중에 보내려면 "나중 시간에 보내고 싶어요"를 눌러 시간을 골라요.

> 처음에는 **본인 번호 1줄**만 넣어서 시험해 보세요.
> 문자를 보내는 폰 자기 자신의 번호로는 보낼 수 없어요. 다른 사람 번호로 시험하세요.

## 3단계. 결과 보기

- 캠페인 화면에 **참석 / 불참 / 답 없음 / 확인 필요** 숫자가 크게 나와요.
- **사업장별로 보기**에서 사업장 이름을 누르면 그 사업장만 보여요.
- **확인 필요**: 컴퓨터가 답장 뜻을 잘 모르는 경우예요. 내용을 보고 **참석** 또는 **불참** 버튼으로 직접 정해 주세요.
- **답 없는 사람에게 다시 보내기**: 답이 없거나 못 보낸 사람에게만 다시 보내요.
- **엑셀로 저장하기**: 결과를 파일로 내려받아요.

| 답장 | 결과 |
|---|---|
| 참석합니다, 네, 갈게요, 1 | 참석 |
| 불참, 미참, 못 갑니다, 어려워요, 2 | 불참 |
| 시간을 바꿀 수 있나요? (질문) | 확인 필요 → 직접 확인 |

## 문자함 (면접 안내 말고 문자 보내기/받기)

위쪽 **문자함**에서 원하는 번호로 문자를 보내고, 받은 문자와 보낸 문자를 볼 수 있어요.
각 줄의 **답장**을 누르면 그 번호로 바로 답장할 수 있어요. 번호는 공백이나 줄바꿈으로 나눠 20명까지 한 번에 보낼 수 있어요.

## 자주 묻는 질문

**문자가 안 가요.**
설정 화면의 **연결된 폰**에서 **잘 연결됐는지 확인**을 눌러 보세요. 폰이 꺼져 있거나, 앱이 Online이 아니거나, 문자 권한이 허용되지 않았을 수 있어요.

**답장이 화면에 안 나와요.**
설정 → 연결된 폰 → **답장 받기 다시 설정**을 눌러 보세요.

**비밀번호를 잊었어요.**
전체 관리자가 설정 → **이 시스템을 쓸 사람 관리하기** → **비밀번호 바꿔주기**를 해 줘요.

**개인정보는 얼마나 보관되나요?**
기본 90일이에요. 지나면 이름, 전화번호, 문자 내용이 저절로 지워지고 사업장별 숫자만 남아요.

**PC가 꺼지면요?**
지금은 이 PC에서 시스템이 돌아가요. PC가 켜져 있어야 문자를 보내고 답장을 받을 수 있어요.
