# 처음 쓰는 분을 위한 사용 안내

면접 보는 분들에게 문자로 안내를 보내고, "참석" / "불참" 답장을 자동으로 모아 보여주는 시스템입니다.
접속 주소: **https://interview.bigbears.me**

## 전체 흐름 (딱 3단계)

1. **폰 연결** — 문자를 보낼 회사 폰을 시스템에 연결합니다. (폰마다 처음 한 번만)
2. **명단 올리고 발송** — 엑셀 명단을 올리고 "발송"을 누릅니다.
3. **결과 보기** — 참석 / 불참 / 아직 답 없음을 사업장별로 확인합니다.

---

## 1단계. 폰 연결 (전체 관리자만)

화면 위쪽 **설정** 메뉴에 안내가 그대로 나와 있습니다. 아래는 같은 내용을 풀어 쓴 것입니다.

### A. 폰에 앱 설치
1. 폰에 **SMS Gateway** 앱을 설치합니다. (GitHub 릴리스의 APK)
2. 앱을 처음 열 때 **문자(SMS) 권한 → 허용**을 누릅니다.

> **허용 버튼이 회색이라 안 눌린다면** (갤럭시 등 안드로이드 13 이상에서 흔합니다)
> 1. 회색 허용 버튼을 한 번 누르고 나옵니다.
> 2. 설정 → 애플리케이션 → SMS Gateway 로 들어갑니다.
> 3. 오른쪽 위 **⋮** → **"제한된 설정 허용"** → 지문/PIN 인증
> 4. 다시 권한 → 문자(SMS) → **허용**

### B. 앱에 서버 정보 입력
1. 앱의 **설정 → Cloud Server** 로 이동합니다.
2. **설정** 화면 ①번 안내에 표시된 두 값을 **복사 버튼**으로 복사해 붙여넣습니다.
   - 서버 주소 (API URL)
   - 비밀 토큰 (Private Token)
3. 앱 첫 화면에서 **Cloud server** 스위치를 켜고 **Offline** 버튼을 눌러 **Online** 이 될 때까지 기다립니다.
4. 앱에 **Username** 과 **Password** 가 나타납니다. 이 두 값을 다음 단계에서 씁니다.

### C. 웹에서 연결
1. 웹 **설정** 화면 ②번 "폰 연결하기"에서 부서를 선택(없으면 새 부서 이름 입력)하고,
   앱의 **Username / Password** 를 입력한 뒤 **연결하기**를 누릅니다.
2. 아래 ③번 목록에서 **연결 확인**을 눌러 "정상입니다"가 나오면 끝입니다.

> 앱을 지우고 다시 설치하면 Username/Password 가 바뀝니다.
> 목록의 **계정 변경**에서 새 값을 입력하면 됩니다.

---

## 2단계. 명단 올리고 발송

1. 메인 화면의 **"명단 양식 내려받기"** 로 엑셀 양식을 받습니다. (사업장 / 이름 / 전화번호 / 면접일시)
2. 지원자 정보를 채우고 **CSV로 저장**합니다.
3. **새 캠페인**에서 이름을 적고, 보낼 폰을 고르고, CSV 파일을 선택한 뒤 **생성**을 누릅니다.
   - 사업장 이름은 명단에 적은 그대로 자동으로 나뉩니다.
   - 번호가 잘못되었거나 중복된 줄은 제외되고, 이유가 화면에 표시됩니다.
4. 캠페인 화면에서 **예약/즉시 발송**을 누릅니다. 시각을 비워 두면 바로 보내고, 정하면 그 시각에 보냅니다. (한국시간)

> 처음에는 **본인 번호 1건**만 넣어서 시험해 보세요.
> 폰은 보내는 폰 자신의 번호로는 문자를 보낼 수 없으니, 다른 폰 번호로 시험하세요.

## 3단계. 결과 확인

- 캠페인 화면에 **사업장별 참석 / 불참 / 미응답 / 확인필요** 숫자가 나옵니다. 사업장 이름을 누르면 그 사업장만 보입니다.
- **확인필요**: 답장 내용을 컴퓨터가 판단하지 못한 경우입니다. 내용을 보고 **참석 / 불참** 버튼으로 직접 정해 주세요.
- **미응답자 리마인드 발송**: 답이 없는 분께만 다시 보냅니다.
- **CSV 내보내기**: 결과를 엑셀로 저장합니다.

### 어떤 답장을 어떻게 읽나요?
| 답장 예시 | 결과 |
|---|---|
| 참석합니다, 네, 갈게요, 1 | 참석 |
| 불참, 미참, 못 갑니다, 어려워요, 2 | 불참 |
| 시간 변경 가능한가요? (질문) | 확인필요 → 직접 확인 |

## 문자함 (캠페인 없이 문자 보내기/받기)

상단 **문자함** 메뉴에서 원하는 번호로 바로 문자를 보내고, 받은 문자와 보낸 문자 내역을 봅니다.
각 줄의 **답장** 링크를 누르면 그 번호로 바로 답장할 수 있습니다.

## 자주 묻는 질문

**Q. "발송요청"이라고 나오는데 문자가 안 가요.**
폰이 꺼져 있거나 앱이 Online이 아니거나 문자 권한이 허용되지 않은 경우입니다.
설정 → 연결된 폰 → **연결 확인**을 눌러 보고, 폰에서 앱이 Online인지, 문자 권한이 허용인지 확인하세요.

**Q. 답장이 화면에 안 떠요.**
설정 → 연결된 폰 → **답장 수신 다시 설정**을 한 번 눌러 보세요.

**Q. 비밀번호를 잊었어요.**
전체 관리자가 설정 → 관리자 계정 → **비밀번호 재설정**을 해 줍니다.

**Q. 개인정보는 얼마나 보관되나요?**
캠페인을 만들 때 보관 기간(기본 90일)을 정합니다. 기간이 지나면 이름·전화번호·문자 내용이 자동으로 지워지고 사업장별 숫자만 남습니다.

**Q. PC가 꺼지면요?**
시스템이 이 PC에서 돌아가므로 PC가 켜져 있어야 발송과 답장 수신이 됩니다. (추후 회사 서버로 옮길 예정)
