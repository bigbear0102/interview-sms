# 사용 안내 (문자 관리 시스템)

문자를 **보내고, 받고, 예약해서 보내는** 시스템이에요. 면접 안내처럼 여러 명에게 한꺼번에 보내고 답장을 모으는 기능도 들어 있어요.

- 접속 주소: **https://interview.bigbears.me**
- 화면의 안내 글은 이 문서와 같은 내용이에요. 막히면 화면의 안내를 그대로 따라 하면 돼요.

## 처음 쓰는 직원

1. 주소(https://interview.bigbears.me)에서 **회원가입**을 눌러요.
2. **이름, 회사 이메일(@willvi.co.kr), 휴대폰 번호, 부서, 비밀번호**를 적고 가입해요.
3. 회사 메일함으로 온 **인증 메일의 링크**를 눌러요. (24시간 안에)
4. **이메일과 비밀번호**로 로그인해요. 로그인하면 내 부서의 문자와 면접 안내만 보여요.

메일이 안 오면 스팸함을 확인하고, 로그인 화면의 "인증 메일 다시 받기"를 눌러요. 그래도 안 오면 관리자에게 승인을 요청해 주세요.
비밀번호를 잊었다면 로그인 화면의 **비밀번호를 잊으셨나요?**를 눌러요.

## 화면 구성

| 메뉴 | 할 수 있는 일 |
|---|---|
| **홈** | 오늘 보낸/받은 문자 숫자, 예약 대기, 최근 받은 문자, 빠른 실행 |
| **문자 보내기** | 한 명 또는 여러 명(최대 200명)에게 지금 보내거나 예약해요 |
| **문자함** | 받은 문자, 보낸 문자를 보고 바로 답장해요 |
| **예약 문자** | 예약한 문자를 확인하고 취소해요 |
| **면접 안내** | 면접 대상자 명단으로 한꺼번에 보내고 참석 여부를 모아 봐요 |
| **설정** | 문자 보내는 폰 연결, 부서, 로그인 계정 (전체 관리자) |

## 처음 시작하기 (3단계)

1. **폰 연결** — 문자를 보낼 회사 폰을 시스템에 연결해요. (폰 1대당 한 번만)
2. **명단 올리고 보내기** — 엑셀 명단 파일을 올리고 "지금 바로 보내기"를 눌러요.
3. **결과 보기** — 참석 / 불참 / 답 없음 숫자를 사업장별로 확인해요.

---

## 1단계. 폰 연결하기 (전체 관리자만)

웹의 **설정** 화면에 1~7번 단계가 큰 글씨로 나와 있어요. 복사 버튼도 있어요. 아래는 같은 내용이에요.

### 1) 앱 설치하기
1. 폰에서 **인터넷(크롬)**을 열어요.
2. 주소 칸에 `github.com/capcom6/android-sms-gateway/releases` 를 입력하고 이동해요.
3. 맨 위 최신 버전에서 **Assets**를 눌러 펼쳐요.
4. 이름이 **.apk**로 끝나는 파일을 눌러요. (이름에 `insecure`가 들어간 것은 고르지 마세요.)
5. 다운로드가 끝나면 **열기** → **설치**를 눌러요. "이 출처 허용" 화면이 나오면 스위치를 켜고 뒤로 가서 다시 **설치**를 눌러요.
6. 설치가 끝나면 **열기**를 눌러 **SMSGate** 앱을 열어요.

### 2) 문자 보내기 허용하기
1. 앱을 열면 "문자를 보내도록 허용할까요?" 창이 나와요. **허용**을 눌러요.
2. "전화 걸기/관리" 창이 나오면 그것도 **허용**을 눌러요.

**허용 버튼이 회색이라 눌리지 않을 때** (갤럭시 폴드 등에서 자주 생겨요)
1. 안 눌리는 **허용** 버튼을 **한 번 눌러 보고** 나와요.
2. **설정** 앱 → **애플리케이션**(또는 **앱**) → **SMSGate**를 눌러요.
3. 화면 **오른쪽 위 점 세 개(⋮)**를 눌러요.
4. **제한된 설정 허용**을 누르고, 지문이나 비밀번호로 확인해요.
5. 뒤로 가서 **권한** → **문자(SMS)** → **허용**을 눌러요.

### 3) 문자 앱의 "채팅(RCS)" 기능 끄기 (꼭 해야 해요)
갤럭시 폰은 문자가 일반 문자가 아니라 **인터넷 채팅 메시지(RCS)** 로 오는 경우가 있어요. 이렇게 오면 SMSGate가 받은 문자를 알아보지 못해요.

**삼성 메시지 앱**
1. **메시지** 앱을 열어요.
2. 오른쪽 위 **점 세 개(⋮)** → **설정**
3. **채팅 설정**(또는 채팅 서비스) → **채팅 기능**을 **꺼요**.

**구글 메시지 앱**
1. 오른쪽 위 **프로필 사진** → **메시지 설정** → **RCS 채팅**
2. **RCS 채팅 사용**을 **꺼요**.

두 앱이 모두 설치되어 있으면 둘 다 꺼요. 끈 뒤 10분쯤 지나면 효과가 나타나요.

### 4) 폰이 꺼지지 않게 설정하기
1. **설정** 앱 → **애플리케이션** → **SMSGate** → **배터리**
2. **제한 없음**을 선택해요.
3. 이 폰은 **충전기에 계속 꽂아 두고** 전원을 켜 두세요.

### 5) 문자 내용 암호화 켜기 (꼭 해야 해요)
이 시스템은 **공개 문자 서버**(`api.sms-gate.app`)를 거쳐 문자를 보내요. 서버가 문자 내용과 전화번호를 볼 수 없도록 **암호 비밀번호**를 정해서 두 곳에 똑같이 넣어요.

1. 폰 **SMSGate** 앱 → **Settings** → **Encryption**(암호화)을 열어요.
2. **Passphrase** 칸에 **길고 아무도 모르는 문장**(12자 이상)을 적고 저장해요.
3. 같은 문장을 웹 **설정** 화면 7번의 **암호화 비밀번호** 칸에도 똑같이 적어요.

- 앱의 **Cloud Server** 서버 주소 칸은 **기본값 그대로** 두세요. (직접 만든 서버를 쓰는 경우에만 주소와 토큰을 넣어요.)
- 암호화를 켜면 배터리를 조금 더 써요.

### 6) 켜기
1. 앱 아래쪽 메뉴에서 **Home**을 눌러요.
2. **Cloud server** 스위치를 **켜요**.
3. **Offline** 버튼을 눌러요.
4. 버튼이 **Online**으로 바뀔 때까지 기다려요. (몇 초)

Online이 안 되면: 서버 주소에 빠진 글자가 없는지, 폰이 인터넷에 연결되어 있는지 확인해요.

### 7) 아이디, 비밀번호, 암호화 비밀번호 옮겨 적기
1. 앱의 **Settings → Cloud Server** 화면에 **Username**(아이디)과 **Password**(비밀번호)가 보여요.
2. 웹 **설정** 화면 7번 칸에 똑같이 적어요. **암호화 비밀번호**에는 5번에서 정한 문장을 적어요.
3. 부서를 고른 뒤 **연결 끝내기**를 눌러요.
4. **연결된 폰** 목록에서 **잘 연결됐는지 확인**을 눌러 "잘 연결되어 있어요"가 나오면 끝이에요.

> 앱을 지우고 다시 설치하거나 서버를 바꾸면 아이디와 비밀번호가 새로 바뀌어요.
> 이때는 목록의 **폰을 다시 설치했어요**를 눌러 새 값을 적어 주세요. (암호화 비밀번호도 새로 정했다면 같이 적어요.)

## 2단계. 명단 올리고 보내기 (면접 안내)

위쪽 **면접 안내** → **새 면접 안내 만들기**를 눌러요.

1. **명단 파일 고르기** — 엑셀에 `사업장(원가중심점), 이름, 전화번호, 면접일시`를 적고 **CSV로 저장**한 파일이에요. **연습용 양식 받기**를 누르면 예시 파일이 내려와요.
   - **사업장(원가중심점)**: 열 이름이 `사업장`, `원가중심점`, `코스트센터` 등이어도 인식해요. 한 곳에만 보낸다면 파일에 열을 만들지 않고 **화면의 "사업장(원가중심점)" 칸에 적으면 전체에 적용**돼요. (예: `아마노코리아(현장HR)`)
   - 사업장 이름은 **문자에는 들어가지 않아요.** 사업장별 회신 현황을 모아 볼 때만 쓰여요.
2. **보낼 문자 확인하기** — 기본 문구가 채워져 있고, 아래 **미리보기**에서 실제로 갈 모양을 볼 수 있어요.
   - `{이름}`, `{면접일시}` 자리에는 사람마다 맞는 정보가 들어가요.
   - 줄바꿈은 그대로 문자에 반영돼요. 불필요한 공백이나 빈 줄은 저절로 정리돼요.
3. **언제 보낼까요?**에서 하나를 골라요.
   - **올린 다음에 제가 직접 보낼게요**: 올린 뒤 다음 화면에서 초록색 **지금 바로 보내기**를 눌러요.
   - **예약해서 보낼게요**: 날짜와 시간을 정해요. 빠른 선택 버튼(**1시간 뒤 / 내일 오전 9시 / 내일 오후 2시**)도 있어요. 시간이 되면 **1분 안**에 저절로 나가요.
4. **명단 올리기**를 눌러요. 예약하지 않았다면 이때는 **아직 문자가 나가지 않아요.**

예약한 뒤에는 캠페인 화면에서 **예약 시간 바꾸기**나 **예약 취소하기**를 할 수 있어요. 단, **폰은 켜져 있고 SMSGate가 실행 중이어야** 해요.

> 처음에는 **본인 번호 1줄**만 넣어서 시험해 보세요.
> 문자를 보내는 폰 자기 자신의 번호로 보내면 문자가 자기 자신에게 돌아와서, 내용 속 "불참"이라는 글자 때문에 **불참으로 집계**될 수 있어요. 시험은 다른 사람 번호로 해 주세요.

## 3단계. 결과 보기

- 캠페인 화면에 **참석 / 불참 / 답 없음 / 확인 필요** 숫자가 크게 나와요.
- **사업장(원가중심점)별 회신 현황** 표에서 사업장마다 **보냄 · 회신 · 회신율 · 참석 · 불참 · 확인 필요 · 답 없음**을 한눈에 봐요. 사업장 이름을 누르면 그 사업장 사람만 보여요.
- **보낼 문자 미리보기**로 실제로 간 문자 모양을 확인할 수 있어요.
- **확인 필요**: 컴퓨터가 답장 뜻을 잘 모르는 경우예요. 내용을 보고 **참석** 또는 **불참** 버튼으로 직접 정해 주세요.
- **답 없는 사람에게 다시 보내기**: 답이 없거나 못 보낸 사람에게만 다시 보내요.
- **엑셀로 저장하기**: 결과를 파일로 내려받아요.

| 답장 | 결과 |
|---|---|
| 참석합니다, 네, 갈게요, 1 | 참석 |
| 불참, 미참, 못 갑니다, 어려워요, 2 | 불참 |
| 시간을 바꿀 수 있나요? (질문) | 확인 필요 → 직접 확인 |

## 문자함 (면접 안내 말고 문자 보내기/받기)

위쪽 **문자함**에서 원하는 번호로 문자를 보내고, 받은 문자와 보낸 문자를 볼 수 있어요.
각 줄의 **답장**을 누르면 그 번호로 바로 답장할 수 있어요. 번호는 공백이나 줄바꿈으로 나눠 20명까지 한 번에 보낼 수 있어요.

## 자주 묻는 질문

**다른 폰이 보낸 답장이 안 들어와요.**
게이트웨이 폰의 문자 앱에는 오는데 SMSGate에 안 잡히면 거의 **채팅(RCS)** 때문이에요. 위 3)번을 확인하세요.

**문자가 안 가요.**
설정 화면의 **연결된 폰**에서 **잘 연결됐는지 확인**을 눌러 보세요. 폰이 꺼져 있거나, 앱이 Online이 아니거나, 문자 권한이 허용되지 않았을 수 있어요.

**답장이 화면에 안 나와요.**
설정 → 연결된 폰 → **답장 받기 다시 설정**을 눌러 보세요.

**비밀번호를 잊었어요.**
전체 관리자가 설정 → **이 시스템을 쓸 사람 관리하기** → **비밀번호 바꿔주기**를 해 줘요.

**개인정보는 얼마나 보관되나요?**
기본 90일이에요. 지나면 이름, 전화번호, 문자 내용이 저절로 지워지고 사업장별 숫자만 남아요.

**PC가 꺼지면요?**
지금은 이 PC에서 시스템이 돌아가요. PC가 켜져 있어야 문자를 보내고 답장을 받을 수 있어요.

## 알림과 안 읽은 문자

- **안 읽은 답장**은 위쪽 메뉴(모바일은 아래 탭)의 **문자함**에 빨간 숫자로 보여요. 문자함을 열면 읽음 처리돼요. (같은 부서 사람들이 함께 쓰는 받은 편지함이에요.)
- 새 답장을 **메일로도 받고 싶다면** 오른쪽 위 내 이름 → **내 계정**에서 "새 답장이 오면 메일로 알려 주세요"를 켜요. 개인정보 보호를 위해 메일에는 내용을 넣지 않고 확인 링크만 가요. (5분에 한 번)

## 문자가 못 나가면

- 일시적인 오류는 **시스템이 알아서 최대 3번 다시 보내요.** 그 사이에는 "다시 시도해요 (1/3)"처럼 표시돼요.
- 잘못된 전화번호처럼 다시 해도 안 되는 경우는 바로 **못 보냄**으로 표시돼요. 번호를 확인해 주세요.
- 3번 모두 실패하면 **못 보냄**으로 남고, 폰이 정상인지 확인한 뒤 **답 없는 사람에게 다시 보내기**를 눌러요.

## 폰 설치 (Obtainium 사용)
최신 안드로이드는 GitHub 에서 받은 앱의 문자 권한을 막습니다. 그래서 **처음부터 Obtainium** 으로 설치합니다.
메뉴 → 내 이름 → **폰 설치 안내** (`/help/phone`)에 그림 없이 단계별로 정리돼 있고, 막혔을 때 보는 표도 있습니다.
(자동 차단 끄기 → Chrome 알 수 없는 앱 허용 → Obtainium 설치 → SMSGate `app-release.apk` 설치 → 문자 권한 허용 → 채팅(RCS) 끄기 → 배터리 제한 없음)

## 면접 안내: 한 명에게만 보내기 / 홈 현황판
- **면접 안내 만들기**에서 "한 명에게만"을 고르면 사업장·이름·휴대폰·면접일시만 적어 한 사람에게 보낼 수 있어요(파일 불필요). "여러 명"을 고르면 명단 파일을 올려요.
- **홈 → 면접 안내 현황**: 최근 30일, **보낸 날 × 사업장**별로 보냄 / 참석 / 불참 / 확인 필요 / 미회신 수와 합계를 한 표로 봅니다. "참석", "불참" 답장이 오면 자동 반영돼요.

## 면접 결과 기록과 자동 리마인드
- **면접 결과**: 면접 안내 상세의 사람별 표에서 `출석 / 노쇼 / 합격 / 입사 / 불합격`을 고르면 저장돼요. 위쪽에 출석률(출석 ÷ 출석·노쇼 기록)이 보이고, 홈 현황판과 엑셀에도 반영돼요.
- **자동 리마인드**: 면접 안내를 만들 때 체크(기본 켬). "참석"이라고 답한 사람에게 **면접 당일 오전 8시**에 **한 번만** 문자가 가요. (8시 이후에 참석 답장이 와도 면접 시각 전이면 바로 한 번 가요.) 면접일시를 `10/20 14:00`처럼 날짜와 시간을 함께 적어야 해요(못 읽으면 보내지 않아요). 상세 화면에서 켜고 끌 수 있어요. 이미 만들어 둔 안내는 꺼져 있어요.

## 지원자 이력 (`/people`)
면접 안내 목록 위쪽 **지원자 이력**: 같은 전화번호를 한 사람으로 묶어 안내 횟수·참석 답장·출석·노쇼·합격·입사를 보여 줘요. 노쇼가 많은 사람이 위에 나오고 2회 이상이면 "노쇼 반복"이 붙어요. 이름·번호·사업장으로 찾을 수 있고, 개인정보 보관 기간이 지나 파기된 기록은 빠져요.

## 소개 페이지 (`/`, 로그인 전 첫 화면)
- 주소 첫 화면(`/`)은 로그인 전에는 **12장 소개 페이지**, 우측 상단에 **[로그인]** 버튼이 있어요. 로그인 상태에서는 `/intro` 로 다시 볼 수 있어요.
- 스크롤로 한 장씩 읽어요. 인쇄(PDF 저장)하면 장당 한 쪽으로 나와요.
- 화면 예시는 모두 가상 데이터이며, 효과 수치는 시범 운영 후 측정해서 채웁니다. 문구는 `src/landing.js` 의 `SLIDES`.

## 엑셀에서 복사해서 붙여넣기 (면접 안내 만들기 → 여러 명)
- 엑셀에서 표를 드래그해 **복사(Ctrl+C)** 하고, 면접 안내 만들기의 칸에 **붙여넣기(Ctrl+V)** 하면 돼요. CSV로 저장하지 않아도 돼요.
- **제목 줄은 있어도 없어도** 돼요. 없으면 내용을 보고 열을 알아봐요: 휴대폰 번호 모양 → 전화번호, 날짜·시간 모양 → 면접일시, 나머지는 앞에서부터 사업장, 이름 순이에요.
- 열 순서는 **사업장 · 이름 · 전화번호 · 면접일시**를 권해요. 사업장 열이 없으면 아래 "사업장" 칸에 적으세요.
- 엑셀에서 앞의 0이 사라진 번호(1012345678)도 알아봐요. 파일(CSV)로 올리는 방법도 그대로 쓸 수 있어요.

## 홈의 "이번 달 시스템이 대신한 일" 카드
- 이번 달(한국 시간 1일 0시부터) 부서 기준으로 **한 번에 보낸 안내 / 자동으로 분류한 답장 / 자동 리마인드 / 리마인드 뒤 미리 알려 온 불참** 건수와 **절약 시간(추정)** 을 보여 줘요.
- 절약 시간 = 안내 건수 × 1분 + 자동 분류 답장 × 1분 + 자동 리마인드 × 2분. 건당 시간은 사람이 직접 하는 경우를 가정한 값이라 **추정치**예요. 값은 `src/savings.js` 의 `ASSUMPTIONS` 에서 조정해요.
- 직접 정정한 답장(수동 처리)은 자동 분류 건수에서 빠져요. 이번 달 활동이 없으면 카드는 보이지 않아요.

## 지원자 관리 (블랙리스트) — 문자 발송과 별개의 모듈
- 상단 메뉴 **지원자 관리**(모바일은 오른쪽 위 사람 아이콘 메뉴). **한 화면(표)에서 모두 해요.** 지금은 로그인한 모두가 사용할 수 있어요. (권한은 `src/applicants.js` 의 `canUseApplicants` 한 곳에서 바꿔요)
- **추가**: 표 위의 입력 줄에 이름 · 전화번호 · 지원한 곳 · 직무를 적고 **추가**를 눌러요. 같은 전화번호는 한 사람으로 합치고 지원 건만 추가돼요.
- **CSV·엑셀로 한꺼번에 등록**: 파일(CSV)을 올리거나, 엑셀에서 복사해 붙여넣어요(한 번에 200명, 제목 줄 없어도 됨). **양식 받기**로 예시 파일을 받을 수 있어요.
  - 열: **이름 · 전화번호 · 지원한 곳 · 직무 · 블랙리스트 · 사유 · 사유 설명** (앞의 네 칸만 있어도 돼요).
  - **블랙리스트** 칸에 Y(또는 예, O, 1)를 적으면 블랙리스트로 등록하고, 비워 두거나 N이면 일반이에요. **사유**는 목록 이름(면접 무단 불참, 근무 중 무단 이탈, 서류·정보 허위, 업무상 부적절한 행위, 기타) 또는 비슷한 말(노쇼, 이탈, 허위 등)을 적어요. 목록에 없는 말은 "기타"로 들어가고 적은 말이 설명으로 남아요.
  - 사유가 없거나 "기타"인데 설명이 없으면 **일반으로 등록**하고, 등록 후 위쪽 안내에 몇 번째 줄인지 알려 줘요. 이미 블랙리스트인 사람은 그대로 두고, 업로드로 등록한 변경 기록에는 "(업로드)"가 붙어요.
- **수정**: 표의 **수정**을 누르면 칸이 입력창으로 바뀌고 **저장**을 누르면 돼요. (지원한 곳·직무는 가장 최근 지원 건에 반영돼요)
- **블랙리스트**: 표의 **블랙리스트**에서 사유를 목록(면접 무단 불참 / 근무 중 무단 이탈 / 서류·정보 허위 / 업무상 부적절한 행위 / 기타)에서 골라 등록해요. **기타는 사유 설명이 필수**예요. **해제**는 **수동**이고(자동 만료 없음) 해제·재등록 이력이 남아요.
- **기록**: 표의 **기록**을 누르면 그 줄 아래에 지원 이력, 블랙리스트 기록, 변경 기록(누가·언제·무엇)이 펼쳐져요. **상세**로 들어가면 같은 내용을 한 페이지로 볼 수 있어요. 삭제는 관리자만 상세 화면에서 할 수 있어요.
- **중복은 올리지 않아요**: 같은 번호 + 같은 지원 건(지원한 곳·직무)이나 이미 등록 중인 블랙리스트는 다시 올리지 않고, **새 내용만** 반영해요. 결과 안내에 "새로 N명 / 기존 N명에게 새 내용 추가 / 중복 N건은 올리지 않았어요"가 나와요. 번호는 같은데 이름이 다르면 기존 이름을 유지하고 알려 줘요.
- **업로드 되돌리기**: 업로드 직후 안내의 "방금 업로드 되돌리기"나 "최근 업로드" 목록의 "되돌리기"를 누르면 그 업로드로 생긴 사람·지원 건·블랙리스트가 사라져요. 업로드 뒤에 직접 바뀐 사람은 남겨 둬요.
- **번호로 바로 확인**: 맨 위 칸에 번호를 넣고 "확인"을 누르면 블랙리스트인지 바로 알려 줘요(사유 포함).
- **필터·정렬·쪽**: "상세 필터·정렬"에서 지원한 곳, 직무, 사유, 등록일 범위, 정렬(최근 변경 / 등록일 / 이름)을 고르고, 50명씩 쪽으로 넘겨요.
- **사유 수정**: 블랙리스트 줄의 "사유 수정"(또는 상세)에서 사유를 바꿀 수 있고 변경 기록에 남아요.
- **보관**: 지원자 정보는 자동으로 지우지 않아요. 오래 쓰지 않은 지원자도 계속 보관돼요. 삭제는 관리자가 상세 화면에서 직접 해요.
- **문자 시스템 연결** (지원자 관리 화면의 "문자 시스템 연결"): **기본은 꺼짐**이고, 관리자만 바꿀 수 있어요. 연결을 켜면 항목을 골라 쓸 수 있어요. **어떤 항목도 문자 발송을 막지 않아요.**
  - **자동 등록**: 면접 안내를 만들면 명단이 지원자로 등록돼요(지원한 곳에는 사업장). 이미 있는 사람·같은 지원한 곳은 올리지 않아요. 한 번에 400명까지.
  - **이력 보이기**: 지원자 상세와 "기록"에 그 사람의 면접 안내 이력(안내 이름, 사업장, 응답, 면접 결과)이 보여요. 관리자가 아니면 자기 부서의 면접 안내만 보여요.
  - **노쇼 후보 제안**: 면접 결과를 "노쇼"로 기록한 횟수가 기준(기본 3회, 1~20회) 이상인 사람이 표 위에 후보로 나와요. **블랙리스트 등록**(사유 면접 무단 불참)이나 **무시**를 사람이 골라요. 무시한 사람은 노쇼가 더 늘어나면 다시 나와요.
  - **참고 표시**: 면접 안내 명단을 올린 직후와 면접 안내 상세 표에 블랙리스트 대상이 "참고"로 표시돼요.
