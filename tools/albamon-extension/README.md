# 연락처 가져오기 (크롬 확장)

각 사용자의 **자기 PC 크롬**에서 돌아가요. 알바몬 아이디·비밀번호는 다루지 않고, 그 크롬에 이미 로그인된 알바몬 상태를 써요.

## 설치 (한 번만)
1. 크롬 주소창에 `chrome://extensions` 를 입력해요.
2. 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `albamon-extension` 폴더를 골라요.
4. 크롬에서 알바몬 기업회원으로 **로그인**해 둬요.
5. 확장 아이콘(퍼즐 조각)에서 "연락처 가져오기"를 눌러 **연결 키**(`ag_...`)를 넣고 저장해요.
   키는 시스템의 지원자 관리 → 메일 수신함 → "연결 키 만들기"에서 받아요.

## 그룹웨어 메일 가져오기 (v1.1.0)
- 아이콘을 눌러 **내 그룹웨어 아이디·비밀번호**를 넣으면, 5분마다 내 그룹웨어 메일함에서 알바몬 지원 메일을 찾아 내 수신함에 넣어요.
- 아이디·비밀번호는 **이 PC의 크롬에만** 저장되고 시스템으로는 보내지 않아요. 메일을 열기 때문에 그룹웨어에서 **읽음**으로 바뀌어요.
- 연결 키는 수신함에서 **내 연결 키 만들기**로 사람마다 따로 받아요.

## 웹 화면에서 설정 (v1.2.0)
수신함의 "내 확장 프로그램" 카드에서 **내 연결 키 만들기**를 누르면 확장에 자동 연결되고, **내 그룹웨어 아이디·비밀번호**를 입력해 **내 확장에 저장**하면 이 PC의 확장에만 저장돼요(서버로 보내지 않아요). 팝업에서 직접 입력해도 돼요.

## 알바몬 계정 여러 개 (v1.7.0)
관리자가 시스템 연결 설정에 알바몬 계정을 등록하면, **관리자에게 연결된 이 확장**이 계정 목록을 받아 계정마다 로그인 쿠키를 보관해 두고 바꿔 끼우며 모든 담당자의 요청을 처리해요. 처음 보는 공고는 계정을 차례로 시도하고, 성공한 계정을 시스템이 기억해 다음부터 힌트로 줘요. 처리 전후로 이 크롬의 내 알바몬 로그인을 보관·복원해요. 로그인에 실패한 계정은 비밀번호가 바뀔 때까지 다시 시도하지 않아요. 시험: `xvfb-run node tools/albamon-extension/mock-multi.mjs`(CI "Extension test").

## 쓰는 법
수신함에서 **연락처 가져오기**(또는 모두 요청)를 눌러요. 크롬이 켜져 있으면 1분 안에 알아서 이력서를 열어 번호를 채우고 탭을 닫아요.

## 안전
- 결제·이용권 확인 창이 뜨는 예외 상황에서는 누르지 않고 멈춰요(아이콘에 `!` 표시).
- 한 번에 최대 5건, 건마다 몇 초씩 쉬어요.
- 시험 실행을 켜면 연락처 보기를 누르지 않고 버튼만 확인해요.
