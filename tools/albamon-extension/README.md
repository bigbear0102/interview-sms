# 연락처·이력서 가져오기 (크롬 확장, v1.9)

**연락처 가져오기 전용**이에요. 이 PC 크롬에 로그인된 알바몬(기업회원)으로, 새 지원에서 "연락처 가져오기"를 누른 건의 이력서를 열어 연락처를 채워요. 알바몬 아이디·비밀번호는 다루지 않아요.
(v1.9 부터 연락처와 함께 **이력서 화면 전체**(글 전체, 항목·값, 구역 제목)를 시스템에 저장해요. 이미 연락처를 가져온 사람은 새 지원 화면의 "이력서 내용 가져오기"로 이력서만 다시 읽어요 — 이때는 연락처 보기 버튼을 누르지 않아요. 접힌 "더보기"·"펼치기"만 열고, 결제·지원 관련 버튼은 누르지 않아요.)
(v1.8 부터 그룹웨어 메일 가져오기는 시스템이 POP3 로 직접 해요. 예전 버전이 이 PC 에 저장한 그룹웨어 계정·비밀번호는 업데이트하면 자동으로 지워져요.)

## 설치 (한 번만)
1. 시스템 **연결 설정**에서 "확장 프로그램 내려받기"로 받아 압축을 풀어요.
2. 크롬 주소창에 `chrome://extensions` → **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 풀어 둔 폴더 선택.
3. 연결 설정 화면을 새로고침하면 연결 키가 자동으로 들어가요.
4. 같은 크롬에서 알바몬 기업회원으로 **로그인**(문자 인증 포함)해 둬요.

## 어떻게 진행되나
1. 새 지원에서 "연락처 가져오기"(또는 원가중심점이 정해진 공고의 새 지원)는 시스템에 **요청**으로 쌓여요.
2. 확장은 **30초마다**(크롬 알람 최소 주기) 요청을 확인해요. 같은 크롬에서 시스템 화면으로 요청하면 **바로** 깨어나요.
3. 요청을 20건씩 받아 **4건씩 동시에** 이력서 탭을 열고(최대 3초 로딩 대기), 화면에 연락처 보기 버튼이나 번호가 보일 때까지 기다렸다가(최대 10초) 눌러서 번호가 보이면(최대 12초) 읽어 시스템에 보내고 탭을 닫아요.
4. 이용권 차감·결제 확인 창이 보이면 누르지 않고 멈춰요.

## 안전
- 결제·이용권 확인 창이 뜨는 예외 상황에서는 누르지 않고 멈춰요(아이콘에 `!` 표시).
- 시험 실행을 켜면 연락처 보기를 누르지 않고 버튼만 확인해요.
- 시험: CI "Extension test"(실제 크롬 + 가짜 알바몬, `mock-ext.mjs`, `mock-multi.mjs`).
