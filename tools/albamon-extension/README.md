# 연락처 가져오기 (크롬 확장)

각 사용자의 **자기 PC 크롬**에서 돌아가요. 알바몬 아이디·비밀번호는 다루지 않고, 그 크롬에 이미 로그인된 알바몬 상태를 써요.

## 설치 (한 번만)
1. 크롬 주소창에 `chrome://extensions` 를 입력해요.
2. 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `albamon-extension` 폴더를 골라요.
4. 크롬에서 알바몬 기업회원으로 **로그인**해 둬요.
5. 확장 아이콘(퍼즐 조각)에서 "연락처 가져오기"를 눌러 **연결 키**(`ag_...`)를 넣고 저장해요.
   키는 시스템의 지원자 관리 → 메일 수신함 → "연결 키 만들기"에서 받아요.

## 쓰는 법
수신함에서 **연락처 가져오기**(또는 모두 요청)를 눌러요. 크롬이 켜져 있으면 1분 안에 알아서 이력서를 열어 번호를 채우고 탭을 닫아요.

## 안전
- 이용권 차감·결제 확인 창이 보이면 누르지 않고 멈춰요(아이콘에 `!` 표시).
- 한 번에 최대 5건, 건마다 몇 초씩 쉬어요.
- 시험 실행을 켜면 연락처 보기를 누르지 않고 버튼만 확인해요.
