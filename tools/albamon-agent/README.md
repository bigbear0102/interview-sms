# 알바몬 연락처 가져오기 에이전트

알바몬 지원 알림 메일에는 지원자 연락처가 없고, 이력서 페이지에서 **"연락처 보기"를 눌러야** 보입니다.
이 프로그램은 **담당자 PC의 크롬**으로 알바몬에 로그인해, 문자 관리 시스템에서 **"연락처 가져오기"를 누른 건만** 이력서를 열어 연락처를 읽어 시스템에 채워 줍니다.

## 안전하게 쓰기 위해
- **알바몬 아이디·비밀번호는 이 PC 밖으로 나가지 않고, 파일로도 저장하지 않아요.** (터미널에 입력하거나 크롬 창에서 직접 로그인. 로그인 상태만 `chrome-profile` 폴더에 남아요.)
- **시스템에서 "연락처 가져오기"를 누른 건만** 처리해요. 대기 전체를 한꺼번에 처리하고 싶으면 수신함의 "모두 요청"을 직접 눌러야 해요.
- 연락처를 열람할 때 **이용권 차감·결제 확인 창**이 보이면 **누르지 않고 멈춰요.** 알바몬 화면에서 직접 확인해 주세요.
- 한 번에 최대 10건(`--max`로 조절), 건마다 몇 초씩 쉬어요. 로그인이 안 되면 10분 뒤 멈춰요.
- 알바몬 약관에서 자동화·열람 정책을 허용하는지는 담당자가 확인해 주세요.

## 준비 (처음 한 번)
1. 이 PC에 **Node.js(LTS)** 와 **크롬**이 있어야 해요.
2. 시스템에서: 지원자 관리 → **메일 수신함** → "연락처 자동 가져오기 에이전트" → **연결 키 만들기** → 나온 `ag_...` 키를 복사해요(한 번만 보여요).
3. 이 폴더의 **`start.bat`** 을 더블클릭해요. 처음에는 필요한 파일을 설치하고, **시스템 주소**와 **연결 키**를 물어요. (`agent.config.json`에 저장돼요. 이 파일은 git에 올라가지 않아요.)

## 사용
1. 시스템 수신함에서 연락처가 필요한 건의 **연락처 가져오기**를 눌러요.
2. `start.bat`을 실행해요. 크롬 창이 열려요.
3. **알바몬에 로그인**해요. 터미널에서 아이디·비밀번호를 입력하거나(엔터만 누르면 건너뜀), 열린 크롬 창에서 직접 로그인해도 돼요. 다음부터는 로그인 상태가 유지돼요.
4. 요청한 건을 하나씩 열어 연락처를 채워요. 끝나면 시스템 수신함에서 **등록**만 누르면 돼요. (수신함의 "연락처를 가져오면 바로 지원자로 등록"을 켜면 자동 등록돼요.)

## 옵션
| 옵션 | 설명 |
|---|---|
| `--dry` | 시험 실행: 연락처 보기 버튼이 있는지만 확인하고 누르지 않아요 |
| `--once` | 처리할 건이 없으면 기다리지 않고 바로 끝내요 |
| `--max 5` | 한 번에 처리할 최대 건수 |
| `--reset` | 저장된 시스템 주소·연결 키를 다시 입력해요 |

환경변수: `CHROME_PATH`(크롬 경로), `AGENT_SERVER_URL`, `AGENT_TOKEN`, `AGENT_DEBUG=1`(자세한 로그).

## 문제가 생기면
| 증상 | 확인 |
|---|---|
| "연결 키가 맞지 않아요" | 수신함에서 키를 다시 만들고 `--reset`으로 새로 입력 |
| "연락처 보기 버튼을 찾지 못했어요" | 알바몬 화면 구조가 달라졌을 수 있어요. `AGENT_DEBUG=1`로 실행한 로그를 알려 주세요 |
| 로그인이 계속 요구돼요 | `chrome-profile` 폴더를 지우고 다시 로그인해요 |
| 이용권 확인 창 때문에 멈춤 | 알바몬 화면에서 직접 열람한 뒤 다시 실행해요 |

## 개발자용 시험
- `npm test`(프로젝트 루트): 판단 로직(`lib.mjs`) 단위 시험 포함.
- `node mock-run.mjs`: 가짜 알바몬·가짜 시스템을 띄워 크롬으로 로그인 → 클릭 → 번호 읽기 → 결과 전달을 확인해요(실제 사이트에 접속하지 않아요).

## (준비 중) 회사 서버에서 무인으로 돌리기 — `service.mjs`
확장 프로그램 대신 **항상 켜진 서버**(회사 서버 등, 화면 없음)에서 돌리기 위한 준비물이다. 아직 운영에서 쓰지 않는다(브랜치 `company-server-agent`).
- `service.mjs`: 20초마다 요청을 확인해 이력서를 열고 번호를 채운다. 공용 연결 키(`AGENT_TOKEN`)로 모든 담당자 요청을 처리. 알바몬 아이디·비밀번호는 서버의 설정 파일(`ALBAMON_ID`, `ALBAMON_PW`)에만 둔다. 로그인 실패 시 6시간 쉼(계정 잠김 방지), 이용권 창이면 1시간 멈춤.
- `page-read.mjs`: 확장 프로그램의 `pageRead` 와 같은 코드(이력서 읽기).
- 남은 일: 서버 쪽 `POST /api/agent/status`(기기 상태 보고)와 공용 키 마지막 접속 시각 표시, 설치 스크립트(systemd), 가짜 알바몬 시험(`mock-run.mjs` 를 service 모드로), 공용 키 발급 화면.
